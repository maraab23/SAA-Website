Brand & logo

Visual identity of the Sequence Analysis Association

The look of this website is defined in a single brand.yml file (_brand.yml, plus _brand-dark.yml for dark mode). Quarto reads the same file for HTML, revealjs slides, Typst/PDF documents and dashboards, so presentations and reports can share the SAA identity without extra styling work.

The logo

The signet is a stylised sequence index plot: five sequences of coloured episodes (states). In the horizontal logo the bottom sequence continues underneath the wordmark as a timeline. The wordmark is set in Saira (SemiBold for “Sequence Analysis”, Regular for “Association”); all logo files have their text converted to outlines.

Usage rules

  • Clear space: at least the height of two signet rows (≈ ⅓ of the logo height) on all sides.
  • Minimum size: horizontal logo ≥ 120 px wide on screen (≈ 30 mm in print); smaller than that, use the signet alone, and below 32 px the favicon.
  • Use the dark version on navy or darker backgrounds and the white version on photos or saturated colours — never the colour logo on mid-tone backgrounds.
  • Do not recolour, stretch or re-arrange the bars, add effects, or re-set the wordmark in another font.

Blue-700 is used for links and buttons (8.3 : 1 contrast on white). Blue-500 is for accents and large text only (3.8 : 1); on dark backgrounds sky-200, blue-400 and violet-300 replace the darker tones.

Typography

Role Typeface Sample
Logo, headings, navigation Saira 400 / 600 Sequence Analysis Association
Body text Noto Sans 400 / 600 / 700 Trajectories, transitions and turning points.
Code Fira Code 400 / 500 seqdef(data, var = 1:12)

All three are Google Fonts under the SIL Open Font License. Fira Code ligatures (<-, |>, != …) are switched on in code blocks and off in inline code, so running text shows exactly what readers have to type:

seq <- seqdef(biofam, var = 10:25) |> seqdist(method = "OM", sm = "TRATE")

Using the brand elsewhere

Copy _brand.yml together with the logos/ and favicons/ folders into any Quarto project and it is picked up automatically:

# slides.qmd
format: revealjs   # or typst, pdf, dashboard ...
brand: _brand.yml
